# Homepage carousel images

The three banner images on `index.html` live here: `slide-1.jpg`, `slide-2.jpg` and `slide-3.jpg`.

To change a picture, replace the file with one of the same name. Photo 3 is by Gillian Elsom. Wide images (about 3:1, e.g. 1800 x 600 px) fit the banner best. Update the `alt` text in `index.html` if the subject changes.
