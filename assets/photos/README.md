# Orchid Photos

This folder contains photos for the Hardy Orchid Society website.

## How to Add Photos

1. Go to https://github.com/eshemak/Hardy-Orchid-Society
2. Navigate to the **`assets/photos/`** folder
3. Click **"Add file"** → **"Upload files"**
4. Drag and drop your orchid photos or click to browse
5. Click **"Commit changes"** when done

## Using Photos in the Website

Reference photos in your HTML like this:

```html
<img src="assets/photos/your-photo-name.jpg" alt="Description of orchid">
```

## Organization Tips

- Use descriptive names: `hardy-orchid-spring-2026.jpg`
- Supported formats: `.jpg`, `.png`, `.gif`, `.webp`
- Keep file sizes reasonable for web (compress before uploading if large)
